УЛУЧШИТЬ БЛОК «РАСЧЕТ СТОИМОСТИ ПРОЖИВАНИЯ» — AL MARE

Задача: сделать поля выбора дат полностью кликабельными и обновить тексты блока.

==================================================
1. ПОЛНАЯ КЛИКАБЕЛЬНОСТЬ ПОЛЕЙ ДАТ
==================================================

Поля:

— Дата заезда  
— Дата выезда  

Должны открывать календарь при нажатии В ЛЮБУЮ ТОЧКУ поля.

Сейчас календарь открывается только при нажатии на иконку.
Нужно: клик или tap по всей области поля.

Требования:

✔ Клик по любой части поля открывает календарь  
✔ Работает на мобильных устройствах (tap)  
✔ Работает на десктопе (click)  
✔ Нет «мертвых зон»  
✔ Не только по тексту или иконке  
✔ Удобно для пальца на смартфоне  

==================================================
2. ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ
==================================================

Если используется input type="date":

— Убедиться, что input не перекрыт другими элементами  
— pointer-events включены  
— label / wrapper не блокируют события  
— вся область поля реагирует на клик  

Если используется кастомный календарь:

Повесить обработчик на контейнер поля:

container.addEventListener("click", () => openCalendar());

или:

onclick="openCheckInCalendar()"

==================================================
3. РЕКОМЕНДУЕМАЯ СТРУКТУРА ПОЛЯ
==================================================

Каждое поле должно быть единым кликабельным блоком:

<div class="date-field" onclick="openCheckInCalendar()">
  <input type="text" readonly />
  <span class="calendar-icon"></span>
</div>

Важно:

✔ input readonly  
✔ весь контейнер кликабельный  
✔ иконка не блокирует нажатия
