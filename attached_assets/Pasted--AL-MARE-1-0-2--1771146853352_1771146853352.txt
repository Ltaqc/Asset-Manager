УЛУЧШИТЬ БЛОК «РАССЧИТАТЬ СТОИМОСТЬ ПРОЖИВАНИЯ» — AL MARE

1) УВЕЛИЧИТЬ КОЛИЧЕСТВО МАЛЫШЕЙ (0–2)

В блоке состава гостей изменить максимум для поля:

Малыши (0–2)

Было: максимум 2  
Нужно: максимум 4  

Требования:

✔ Кнопка "+" работает до значения 4  
✔ После 4 увеличение блокируется  
✔ Кнопка "–" уменьшает значение до 0  
✔ Работает на мобильных и десктопе  
✔ Значение не может стать отрицательным  

------------------------------------------------------------

2) ПРОВЕРКА ВЫБОРА ДАТ ПЕРЕД РАСЧЁТОМ

Если пользователь нажимает кнопку
«Рассчитать стоимость проживания»
БЕЗ выбранных дат заезда или выезда —

НЕ выполнять расчёт.

Вместо этого показать всплывающее уведомление (toast).

------------------------------------------------------------

3) ТЕКСТ УВЕДОМЛЕНИЯ

Текст:

"Выберите даты проживания"

------------------------------------------------------------

4) ПОВЕДЕНИЕ УВЕДОМЛЕНИЯ

✔ Появляется по центру экрана или над кнопкой  
✔ Показывается 2–3 секунды  
✔ Плавное появление (fade-in)  
✔ Плавное исчезновение (fade-out)  
✔ Не блокирует интерфейс  
✔ Работает на мобильных и десктопе  

------------------------------------------------------------

5) РЕКОМЕНДУЕМЫЙ СТИЛЬ УВЕДОМЛЕНИЯ

✔ Премиальный внешний вид  
✔ Полупрозрачный тёмный фон  
✔ Белый текст  
✔ Скругления  
✔ Лёгкая тень  
✔ Не выглядит как системная ошибка  

Пример CSS:

.toast {
  position: fixed;
  bottom: 30px;
  left: 50%;
  transform: translateX(-50%);
  background: rgba(0,0,0,0.85);
  color: #fff;
  padding: 14px 20px;
  border-radius: 12px;
  font-size: 16px;
  opacity: 0;
  transition: opacity 0.4s ease;
  z-index: 9999;
}

.toast.show {
  opacity: 1;
}

------------------------------------------------------------

6) ЛОГИКА ПРОВЕРКИ

Перед расчётом проверить:

— дата заезда выбрана  
— дата выезда выбрана  

Если хотя бы одна дата отсутствует:

✔ показать toast  
✔ НЕ выполнять расчёт  
✔ НЕ отправлять данные
