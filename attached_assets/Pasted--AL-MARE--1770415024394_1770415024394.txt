1) ИСПРАВИТЬ РАСЧЁТ СТОИМОСТИ НОМЕРА
==============================

Сейчас калькулятор считает стоимость номера по месяцу заезда и умножает на общее количество ночей — это неверно.

Нужно считать стоимость номера ПО НОЧАМ, с учётом перехода между месяцами.

Алгоритм:
- checkIn = дата заезда (включительно)
- checkOut = дата выезда (исключительно)
- nights = количество ночей = разница дат
- roomTotal = 0
- для каждой ночи:
  for (let d = checkIn; d < checkOut; d += 1 day):
     определить месяц текущей ночи
     взять тариф номера для этого месяца
     roomTotal += тариф

Тариф должен определяться по дате каждой ночи проживания, а не по месяцу заезда.

2) УПРОСТИТЬ БЛОК «РАСЧЁТ СТОИМОСТИ» СПРАВА
==============================

В правом блоке НЕ нужно отдельно показывать:
— стоимость номера
— стоимость питания

Нужно показывать ТОЛЬКО:
— количество ночей (например: «24 ночи»)
— итоговую сумму (крупно)
— среднюю цену за ночь (мелко под итогом)

Примечание о предварительном расчёте оставить.
