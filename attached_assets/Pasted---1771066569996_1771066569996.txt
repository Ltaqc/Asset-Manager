КРИТИЧЕСКАЯ ПРОБЛЕМА МОБИЛЬНОЙ ВЕРСИИ — НЕРАБОЧАЯ КЛИКАБЕЛЬНОСТЬ

Нужно полностью перепроверить и исправить интерактивность всех элементов
в блоке «Расчет стоимости проживания» на мобильных устройствах.

Сейчас кнопки и элементы нажимаются не во всех местах.
Иногда приходится прокручивать страницу вверх/вниз,
чтобы кнопка сработала.

==================================================
1. ОБЛАСТЬ ПРОБЛЕМЫ
==================================================

Мобильная версия сайта (все смартфоны).

Проблемы наблюдаются в:

— поле выбора даты заезда  
— поле выбора даты выезда  
— выборе количества гостей  
— кнопках + и − (взрослые, подростки, дети, малыши)  
— кнопке «Рассчитать стоимость проживания»  
— других кнопках блока  

==================================================
2. СИМПТОМЫ
==================================================

— Кнопки нажимаются не во всей области  
— Нажатие работает только в отдельных точках  
— Иногда требуется прокрутить страницу  
— Иногда тап вообще не срабатывает  
— UX сильно ухудшен  

==================================================
3. ТРЕБОВАНИЕ
==================================================

Каждый интерактивный элемент должен:

✔ реагировать на тап по всей площади  
✔ иметь большую зону касания (минимум 44×44 px)  
✔ работать без прокрутки страницы  
✔ работать мгновенно  
✔ не иметь «мертвых зон»  

==================================================
4. ВОЗМОЖНЫЕ ПРИЧИНЫ — ОБЯЗАТЕЛЬНО ПРОВЕРИТЬ
==================================================

Проверить и устранить:

— Перекрывающие элементы (overlay)  
— Невидимые блоки поверх (absolute/fixed)  
— Неправильный z-index  
— overflow: hidden / scroll  
— transform: translate / scale  
— position: fixed элементов  
— фиксированную нижнюю панель  
— модальные окна  
— скрытые контейнеры  
— pointer-events: none  
— прозрачные псевдоэлементы  
— ошибки flex/grid  
— проблемы viewport  

Особенно проверить, не перекрывает ли элементы:

✔ нижняя фиксированная панель  
✔ блок акции  
✔ скрытые модальные элементы  
✔ контейнеры с нулевой прозрачностью  

==================================================
5. КНОПКИ + И −
==================================================

Счетчики гостей должны:

✔ иметь увеличенную область нажатия  
✔ реагировать на тап по всей кнопке  
✔ не требовать точного попадания  
✔ быть удобными для пальца  

==================================================
6. КНОПКА «РАССЧИТАТЬ СТОИМОСТЬ»
==================================================

Исправить:

✔ кликабельность по всей площади  
✔ отсутствие перекрытий  
✔ правильный z-index  
✔ отсутствие блокирующих элементов  
✔ корректный tap на мобильных

==================================================

Мобильная версия должна работать идеально:
