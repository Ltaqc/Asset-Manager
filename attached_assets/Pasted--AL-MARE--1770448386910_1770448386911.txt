Нужно переработать сайт AL MARE из одностраничного в многостраничный сайт с навигацией и логикой подбора номеров. Сохрани текущий дизайн, стиль и цветовую палитру.

==============================
1) ВЕРХНЕЕ МЕНЮ (HEADER)
==============================

Сделай фиксированное верхнее меню со следующими элементами:

Навигация (кликабельные вкладки):
— Главная
— Номера
— Питание
— Пляж
— Инфраструктура
— Контакты

Справа в хедере:
— Телефон (кликабельный, tel:)
— Email (кликабельный, mailto:)
— Иконка Telegram (кликабельная)
— Иконка MAX (кликабельная)
— Адрес отеля (текстом)

Меню должно работать как переход между ОТДЕЛЬНЫМИ страницами (routes), а не скролл внутри одной страницы.

==============================
2) СТРУКТУРА СТРАНИЦ САЙТА
==============================

/ (Главная)
— Краткий блок «О отеле»
— Кнопка «Рассчитать стоимость проживания»

/search (Подбор номеров)
— Страница подбора номеров по датам и составу гостей

/rooms (Номера)
— Все категории номеров с описанием и фото

/food (Питание)
— Ultra All Inclusive

/beach (Пляж)

/infrastructure (Инфраструктура)

/contacts (Контакты)

==============================
3) ЛОГИКА КНОПКИ «РАССЧИТАТЬ СТОИМОСТЬ»
==============================

На главной странице НЕ должно быть выбора номера.

Форма на главной:
— Дата заезда
— Дата выезда
— Количество взрослых (18+)
— Подростки (13–18)
— Дети (2–13)
— Малыши (0–2)

После нажатия кнопки «Рассчитать стоимость»:
— пользователь ПЕРЕХОДИТ на страницу /search
— данные передаются через query params или state

==============================
4) СТРАНИЦА /search — ПОДБОР ДОСТУПНЫХ НОМЕРОВ
==============================

На странице /search:

— Покажи список ВСЕХ подходящих категорий номеров
— Номера должны фильтроваться автоматически по вместимости

Правила вместимости:
— Взрослые + дети 2–13 учитываются в основной вместимости номера
— Малыши 0–2:
   • НЕ учитываются в основной вместимости
   • можно добавить ТОЛЬКО ОДНУ люльку в номер
   • если малышей > 1 → номер НЕ подходит

Пример:
— 2 взрослых + 1 ребёнок (2–13) + 1 малыш (0–2):
   • подходит номер минимум на 3 места
   • люлька допустима

— 2 взрослых + 2 малыша (0–2):
   • НЕ подходит ни один номер (2 люльки нельзя)

==============================
5) РАСЧЁТ СТОИМОСТИ НА СТРАНИЦЕ /search
==============================

Для каждого подходящего номера показать карточку:

— Название номера
— Краткое описание
— Фото
— Количество ночей
— Итоговая стоимость проживания
— Средняя цена за ночь
— Кнопка «Выбрать номер»

Важно:
— Стоимость считается с учётом:
   • перехода между месяцами (по ночам)
   • питания Ultra All Inclusive
   • состава гостей
— Люлька (0–2) БЕСПЛАТНО, если допустима

==============================
6) БЛОК «РАСЧЁТ СТОИМОСТИ»
==============================

На карточке номера показывать ТОЛЬКО:
— Количество ночей
— Итоговую сумму (крупно)
— Среднюю цену за ночь

НЕ показывать:
— отдельную строку «номер»
— отдельную строку «питание»
— выбор категории номера

==============================
7) СТРАНИЦА /rooms
==============================

Покажи все номера без фильтра:
— фото
— описание
— вместимость (текстом)
— кнопка «Рассчитать стоимость» (ведёт на /search)

==============================
8) ОБЩИЕ ТРЕБОВАНИЯ
==============================

— Все тексты на русском
— Все цены в рублях (₽)
— Адаптивный дизайн
— Чистая маршрутизация между страницами
— Сохранить текущий визуальный стиль
— Без лишних анимаций
