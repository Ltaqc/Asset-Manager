ЗАДАЧА: ИСПРАВИТЬ ВЫРАВНИВАНИЕ И ШИРИНУ INPUT-БЛОКОВ С ДАТАМИ В МОБИЛЬНОЙ ВЕРСИИ + ПРОВЕРИТЬ КЛИКАБЕЛЬНОСТЬ КНОПКИ

ПРОБЛЕМА (КЛЮЧЕВАЯ):
В мобильной версии сайта элементы с датами:
— input «Дата заезда»
— input «Дата выезда»

НЕ СОВПАДАЮТ ПО ПРАВОМУ КРАЮ с остальными элементами формы.

СЛЕВА они выровнены корректно,
СПРАВА:
— визуально уже остальных элементов,
— иногда не доходят до общей правой линии,
— иногда накладываются друг на друга,
— выглядят как будто имеют другую ширину контейнера.

Эта проблема есть:
— на главной странице
— внутри страницы «Рассчитать стоимость проживания»

⚠️ Остальные элементы формы (гости, кнопка, карточки номеров) ВЫРОВНЕНЫ ПРАВИЛЬНО — их не менять.

---

ЧТО НУЖНО СДЕЛАТЬ:

1️⃣ КОНТЕЙНЕР ФОРМЫ (MOBILE)
Найди основной контейнер формы подбора номеров (mobile):

- width: 100%
- max-width: 100%
- padding-left = padding-right (например 16px)
- box-sizing: border-box
- overflow-x: hidden

Все поля формы должны быть внутри ЭТОГО контейнера.

---

2️⃣ INPUT-БЛОКИ С ДАТАМИ (ГЛАВНОЕ)
Для input-блоков «Дата заезда» и «Дата выезда»:

- width: 100%
- max-width: 100%
- box-sizing: border-box
- margin-left: 0
- margin-right: 0

На мобильной версии:
— располагать СТРОГО ДРУГ ПОД ДРУГОМ
— без flex в одну строку
— без overlap
— правая граница должна совпадать
  с правой границей остальных input / cards формы

❌ НЕ использовать:
- width: 100vw
- отрицательные margin
- transform / translate для центрирования

---

3️⃣ ПРОВЕРКА КНОПКИ
Кнопка:
«Рассчитать стоимость проживания»

Проблема:
— иногда не нажимается с первого раза

Проверь:
- нет ли overlay / absolute-блоков поверх кнопки
- z-index кнопки выше декоративных слоёв
- pointer-events включены
- нет прозрачных элементов поверх кнопки

---

4️⃣ ДЕБАГ (ОБЯЗАТЕЛЬНО):
Временно добавь:
outline: 1px solid red
на контейнер формы (mobile)

Проверь:
— input с датами НЕ выходят за контейнер справа
— правая линия совпадает с остальными элементами

После исправления — убрать outline.

---

РЕЗУЛЬТАТ:
- input «Дата заезда» и «Дата выезда» визуально одной ширины
- правая граница совпадает с остальными элементами
- нет наложений
- кнопка нажимается с первого раза
- desktop-версию НЕ МЕНЯТЬ
