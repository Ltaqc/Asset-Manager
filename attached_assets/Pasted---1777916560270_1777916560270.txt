ЗАДАЧА

Во всплывающем окне, которое открывается из блока/кнопки «Горящие даты июня», заменить текущее фото на новое фото, которое уже подготовлено и лежит в проекте.

НУЖНО СДЕЛАТЬ ТОЛЬКО ЭТО:
— поменять изображение внутри promo-popup / modal
— сохранить текущий текст, кнопки, отступы, стили и логику открытия окна
— ничего больше в модалке не менять

ВАЖНО ПО АДАПТИВУ

1. Desktop / web:
Модальное окно горизонтальное.
Слева фото, справа текстовая часть.

Сделай так:
— фото занимает левую колонку
— текст и кнопка остаются справа
— пропорции визуально аккуратные и премиальные
— фото должно заполнять левую часть красиво, без пустот
— использовать object-fit: cover
— подобрать object-position так, чтобы фото смотрелось выигрышно и не резалось неудачно
— если на фото есть главный объект, он не должен обрезаться

2. Mobile:
Модальное окно вертикальное.
Сверху фото, снизу текстовая часть.

Сделай так:
— фото на всю ширину сверху
— под фото весь текст и кнопка
— фото не должно смотреться “криво”, слишком приближенно или случайно обрезанным
— использовать отдельную высоту/позиционирование для мобильной версии
— object-fit: cover
— подобрать mobile object-position отдельно от desktop, если нужно
— фото должно выглядеть естественно, чисто и премиально

ТЕХНИЧЕСКИ

— замени только источник изображения внутри этой модалки
— если нужно, используй отдельные стили для desktop и mobile
— можно оставить один img/picture, но с корректными responsive-стилями
— если в проекте уже есть оптимизированная версия изображения, используй её
— если есть desktop и mobile версии картинки, подключи обе через picture/srcset
— если отдельной mobile-версии нет, используй одно изображение, но с разным object-position для desktop/mobile

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ

После нажатия на «Горящие даты июня»:
— в веб-версии в модалке слева должно быть новое фото, справа информация
— в мобильной версии в модалке сверху должно быть новое фото, снизу информация
— фото в обеих версиях должно выглядеть аккуратно, без нелепого кадрирования
— текст, кнопка и остальной контент модалки остаются как есть

ПОСЛЕ ИЗМЕНЕНИЯ
