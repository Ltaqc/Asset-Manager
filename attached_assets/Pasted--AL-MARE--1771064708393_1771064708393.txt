СДЕЛАТЬ КОРРЕКТНУЮ ЛОГИКУ КАЛЕНДАРЯ БРОНИРОВАНИЯ ДЛЯ ОТЕЛЯ AL MARE

Задача: исправить поведение календаря выбора дат проживания.

-----------------------------------
1. СЕЗОН ПРОЖИВАНИЯ
-----------------------------------

Сезон бронирования:
01 июня — 15 сентября (включительно)

Все даты вне сезона должны быть недоступны для выбора.

-----------------------------------
2. С КАКОГО МЕСЯЦА ОТКРЫВАТЬ КАЛЕНДАРЬ
-----------------------------------

При открытии календаря:

ЕСЛИ текущая дата ДО 1 июня текущего года:
→ открыть календарь на июнь текущего года
→ установить дату заезда = 1 июня

ЕСЛИ текущая дата ВНУТРИ сезона (01.06 — 15.09):
→ открыть календарь на текущем месяце
→ установить дату заезда = сегодня

ЕСЛИ текущая дата ПОСЛЕ 15 сентября:
→ открыть календарь на июнь следующего года
→ установить дату заезда = 1 июня следующего года

-----------------------------------
3. ПРОШЕДШИЕ ДАТЫ
-----------------------------------

Все даты до сегодняшнего дня:

— неактивные
— некликабельные
— визуально затемнённые (disabled)
— выбрать их невозможно

-----------------------------------
4. ДАТЫ ВНЕ СЕЗОНА
-----------------------------------

Все даты:

— до 01 июня
— после 15 сентября

должны быть:

— disabled
— затемнены
— некликабельны
— не участвуют в выборе диапазона

-----------------------------------
5. АВТОМАТИЧЕСКАЯ УСТАНОВКА ДАТЫ ЗАЕЗДА
-----------------------------------

Если сегодня до сезона:
→ дата заезда = 01 июня текущего года

Если сегодня в сезоне:
→ дата заезда = сегодня

Если сезон закончился:
→ дата заезда = 01 июня следующего года

-----------------------------------
6. ПРИМЕРЫ ЛОГИКИ
-----------------------------------

Сегодня = 15 февраля → открыть июнь текущего года
Сегодня = 1 мая → открыть июнь текущего года
Сегодня = 10 июня → открыть июнь и выделить 10 июня
Сегодня = 1 августа → открыть август и выделить сегодня
Сегодня = 16 сентября → открыть июнь следующего года

-----------------------------------
7. КНОПКА «РАССЧИТАТЬ СТОИМОСТЬ»
-----------------------------------

Исправить кликабельность:

— вся площадь кнопки должна быть активной
— не только текст
— корректная обработка tap/click на мобильных устройствах
— никаких "мертвых зон"

-----------------------------------
8. ТЕХНИЧЕСКАЯ ОСНОВА (JavaScript)
-----------------------------------

Использовать следующую базовую логику:

const today = new Date();
const year = today.getFullYear();

const seasonStart = new Date(year, 5, 1);  // 1 июня
const seasonEnd = new Date(year, 8, 15);   // 15 сентября

let calendarStartDate;

if (today < seasonStart) {
  calendarStartDate = seasonStart;
} else if (today > seasonEnd) {
  calendarStartDate = new Date(year + 1, 5, 1);
} else {
  calendarStartDate = today;
}

-----------------------------------
9. ДОПОЛНИТЕЛЬНО (ЖЕЛАТЕЛЬНО)
-----------------------------------

— Минимальное бронирование = 1 ночь
— Дата выезда автоматически = дата заезда + 1 день
— Нельзя выбрать выезд раньше заезда
— Корректная работа на мобильных и десктопе

-----------------------------------
ЦЕЛЬ:
Календарь должен вести себя как в профессиональных системах бронирования отелей (Booking / Airbnb).
