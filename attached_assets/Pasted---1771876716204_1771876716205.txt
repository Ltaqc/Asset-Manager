ЛОГИКА РАСЧЁТА
--------------------------------------------------

1. Основные места считаются так:

occupied_places = adults + teens + children

2. Малыши считаются отдельно.

3. Если occupied_places превышает вместимость номера — номер НЕ предлагать.

4. Если малышей больше допустимого для номера — номер НЕ предлагать.

5. Калькулятор должен:

✔️ показывать только реально допустимые варианты размещения  
✔️ автоматически подбирать минимально достаточный номер  
✔️ при необходимости предлагать комбинации нескольких номеров  
✔️ НЕ предлагать невозможные варианты
