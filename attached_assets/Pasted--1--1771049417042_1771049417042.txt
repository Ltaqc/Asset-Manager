ИСПРАВИТЬ БЛОК АКЦИИ И НИЖНЮЮ ПАНЕЛЬ БРОНИРОВАНИЯ

1. НИЖНЯЯ ФИКСИРОВАННАЯ ПАНЕЛЬ

— Панель закреплена снизу экрана (position: fixed; bottom: 0; width: 100%)
— Полностью прямоугольная, без скруглений
— На всю ширину экрана
— Темный фирменный цвет сайта
— Высота 64–72px
— Поверх контента
— Работает на мобильной версии и на ПК

Внутри панели:

— Оставить ТОЛЬКО ОДНУ кнопку
— Текст кнопки: "ЗАБРОНИРОВАТЬ"
— Кнопка строго по центру панели
— Удалить любые дубли текста "ЗАБРОНИРОВАТЬ"
— Вся область кнопки полностью кликабельна (не только текст)
— Кнопка с мягким скруглением 10–14px
— Цвет кнопки — фирменный бирюзовый сайта
— Белый текст
— Hover-эффект на компьютере

При нажатии — плавный скролл к блоку расчёта стоимости проживания


2. БЛОК АКЦИИ (ПОДАРОК + НАДПИСЬ)

Создать отдельный элемент акции:

— Расположить СЛЕВА над нижней панелью
— Позиция: fixed
— Находится выше панели примерно на 10–14px
— Визуально связан с панелью
— Не перекрывает центральную кнопку

Внешний вид:

— Круглая иконка подарка
— Справа от неё небольшой бейдж с текстом "АКЦИЯ"
— Фон бейджа — приглушённый премиальный оранжевый (не кислотный)
— Белая иконка подарка
— Белый текст
— Мягкая тень
— Скругления 16–20px
— Весь элемент кликабельный (иконка + текст)


3. ПОВЕДЕНИЕ ПРИ НАЖАТИИ

При нажатии на блок акции открывается модальное окно акции.


4. МОДАЛЬНОЕ ОКНО АКЦИИ — ОБНОВИТЬ ТЕКСТ

Заголовок:
Раннее бронирование — скидка 10%

Описание:
Зафиксируйте лучшую цену на летний отдых
и получите доступ к самым востребованным датам

Список преимуществ:
✔ Ultra All Inclusive без дополнительных расходов
✔ Собственный пляж и аквапарк
✔ Развлечения и инфраструктура включены
✔ Количество номеров по акции ограничено

Футер:
Акция действует до 28 февраля 2026 года


5. КНОПКА ВНУТРИ ОКНА АКЦИИ

Текст: "Рассчитать стоимость проживания"

— Кнопка на всю ширину
— Полностью кликабельна по всей площади
— Без перекрывающих элементов
— При нажатии:
  • закрыть окно акции
  • плавный скролл к калькулятору проживания


6. СОВМЕСТИМОСТЬ

— Работает корректно на мобильной версии и на ПК
— Не перекрывает кнопку чата (если перекрывает — поднять чат выше)
— Все кликабельные зоны работают по всей площади
— Не выходит за края экрана
— Сохраняет премиальный стиль сайта


ЦЕЛЬ:
Создать единый фиксированный блок бронирования с акцентом на акцию раннего бронирования и новым текстом внутри окна.
