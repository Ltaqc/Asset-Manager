ИСПРАВИТЬ ПОЗИЦИОНИРОВАНИЕ КАЛЕНДАРЯ НА МОБИЛЬНЫХ УСТРОЙСТВАХ

Проблема:
При выборе даты выезда календарь открывается со смещением вправо
и частично выходит за пределы экрана.
Часть календаря не видна пользователю.

Это критическая ошибка мобильного UX.

==================================================
ЦЕЛЬ
==================================================

Сделать так, чтобы календарь ВСЕГДА полностью помещался
в пределах экрана смартфона.

Ни одна часть календаря не должна выходить за границы viewport.

==================================================
ТРЕБОВАНИЯ
==================================================

✔ Календарь полностью виден на мобильных устройствах  
✔ Не обрезается справа или слева  
✔ Не уходит за экран  
✔ Открывается по центру или адаптивно  
✔ Работает для полей "Дата заезда" и "Дата выезда"  
✔ Корректно на всех разрешениях  

==================================================
РЕШЕНИЕ (АДАПТИВНОЕ ПОЗИЦИОНИРОВАНИЕ)
==================================================

Если используется кастомный календарь:

— Проверять ширину экрана (viewport width)
— Если календарь выходит за границы — центрировать его
— Ограничить позицию внутри экрана

Пример логики:

• На мобильных устройствах:
  — позиционировать по центру экрана
  — либо привязывать к левому краю экрана
  — не к правому краю поля

==================================================
CSS ДЛЯ МОБИЛЬНОЙ ВЕРСИИ
==================================================

Использовать медиазапрос:

@media (max-width: 768px) {

  .datepicker,
  .calendar-popup {
    left: 50% !important;
    transform: translateX(-50%) !important;
    right: auto !important;
    max-width: 95vw;
    width: auto;
  }

}

==================================================
АЛЬТЕРНАТИВНЫЙ ВАРИАНТ (ЛУЧШИЙ UX)
==================================================

На мобильных устройствах календарь должен открываться:

✔ по центру экрана  
✔ как модальное окно  
✔ поверх контента  
✔ с затемнением фона  

Это стандарт современных сервисов бронирования.

==================================================
ДОПОЛНИТЕЛЬНО ПРОВЕРИТЬ
==================================================

— position: absolute / fixed  
— привязку к родителю  
— overflow контейнеров  
— transform родительских элементов  
— z-index  

==================================================
ОБЯЗАТЕЛЬНОЕ ТЕСТИРОВАНИЕ
==================================================

Проверить на:

✔ iPhone (Safari)  
✔ Android (Chrome)  
✔ разных размерах экранов  
✔ портретной ориентации  

==================================================
РЕЗУЛЬТАТ
==================================================

Календарь полностью виден пользователю,
не смещается вправо,
не обрезается,
удобен для выбора дат.

UX уровня Booking / Airbnb.
